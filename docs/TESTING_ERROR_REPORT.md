## 6. Error Log

### Error #1
- **User:** testuser100 (Failed at the end of the 100-user workflow)
- **Test:** `Rigorous100UsersTest.test_100_users_workflow`
- **Module:** `royalties.services`
- **Expected:** Royalties are calculated successfully based on the streaming records generated by the 100 users.
- **Actual:** `TypeError: unsupported operand type(s) for *: 'decimal.Decimal' and 'float'`
- **Error:** When generating a default `RoyaltyRate` inside `calculate_royalties()`, the `rate_per_stream` fell back to the model's Python `default=0.5000` (a float), resulting in a type clash when multiplied by a `Decimal`.
- **Root Cause:** Django evaluates float defaults directly on instantiated un-saved model objects, rather than casting them to Decimals immediately like it does upon DB retrieval.
- **Fix:** Explicitly cast the rate to a string then Decimal: `rate = Decimal(str(rate_obj.rate_per_stream))` inside `royalties/services.py`.
- **Files Changed:** `royalties/services.py`
- **Verification:** Ran the 100-user test again. The royalties were processed flawlessly.
- **Status:** **FIXED**
